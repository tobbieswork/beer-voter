## 🖨️ Cách mở & Xuất PDF A4:

1. Mở bất kỳ file HTML nào trên trình duyệt Chrome/Edge/Safari:
   - [portfolio/figma-resume.html](file:///Users/tobbiesng/Code/beer-voter/portfolio/figma-resume.html)
   - [portfolio/index.html](file:///Users/tobbiesng/Code/beer-voter/portfolio/index.html)
2. Nhấn nút **Export PDF (A4)** trên thanh công cụ (hoặc nhấn phím `Cmd + P` / `Ctrl + P`).
3. Chọn máy in: **Save as PDF**, khổ giấy: **A4**, lề: **None / Default**, tick chọn **Background graphics**.
4. Nhấn **Save**.
